# Quant Agent Orchestration

Company filings, financial figures, and current news come from separate sources. Comparing them requires matching reporting periods, checking metric definitions, and finding the passages behind management's explanations.

The planned system uses a LangGraph supervisor to coordinate filings research, financial data, quantitative analysis, and risk comparison. Research briefs will link claims to source passages and calculations to their inputs and methods.

Current status: planning and repository scaffold. The application and document corpus are not implemented. Local setup and deployment instructions will accompany the working system.

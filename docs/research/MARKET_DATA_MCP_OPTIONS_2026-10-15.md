## Student offers: approval versus discount

- Alpha Vantage advertises a free educational request-quota upgrade after project verification. The approval process, eligible endpoints, and actual account limits must be confirmed.
- SiftingIO advertises free upgraded access for verified student coursework and capstones, accepting institutional email or GitHub Education membership as verification. Its derived-price definition remains relevant even with upgraded access.
- Twelve Data's individual student offer is a 20% discount for 12 months. Its separate free academic/nonprofit program is institution-based and requires application; individual student status does not guarantee approval.
- FMP offers students a 30% discount. Massive offers a request-based education discount without a published percentage in the reviewed FAQ. These are discounts rather than confirmed free premium subscriptions.
- [SimFin](https://www.simfin.com/en/prices/) also offers students/faculty 50% off Basic and a separate free daily-price/fundamentals tier. An official MCP implementation was not established, so it is a lower-priority fit for this request.

## Forward-estimate finding

- Alpha Vantage documents `EARNINGS_ESTIMATES` for annual and quarterly EPS/revenue consensus, analyst counts, and revision history. The [official MCP implementation](https://github.com/alphavantage/alpha_vantage_mcp/blob/main/api/src/av_api/tools/fundamental_data.py) registers `earnings_estimates` against that endpoint.
- A direct HTTP request with the provider's public `demo` key for IBM returned HTTP 200, `symbol: IBM`, and 41 estimate rows. Fields include fiscal dates, EPS/revenue averages and ranges, analyst counts, and revision fields. The response is retained in ignored `artifacts/alpha-vantage-estimates-demo.json`.
- The browser/search rendering of the same demo URL returned an informational demo-key message, while direct HTTP returned records. Demo behavior is therefore not proof of arbitrary-symbol or personal-free-key access. Test the four actual project tickers with an authorized real key before promising free forward valuation.
- Business Quant's general estimates endpoint description calls the API free, but its more specific MCP entitlement documentation states that free requests return Apple sample estimates for every ticker. The specific plan restriction governs this assessment.
- A vendor-reported forward P/E without inspectable estimate period, definition, timestamp, and denominator is insufficient evidence for our own checked forward-P/E calculation.

## Recommended paths

1. **Free official-MCP path:** validate Twelve Data quote snapshots and Alpha Vantage estimates/fundamentals; request Alpha Vantage educational quota approval if the normal allowance is insufficient. Keep SEC original-source observations for reported financial evidence.
2. **One-provider research using closing prices:** validate Alpha Vantage's free-key estimate and EOD coverage first. This can reduce integration work if intraday prices are unnecessary; show the close date explicitly.
3. **Higher-throughput free quotes:** use Finnhub with an inspected community server or a small project-owned MCP adapter, while establishing a separate estimate source.
4. **Fast no-key prototype:** evaluate a self-hosted yfinance MCP. Treat coverage and reliability as exploratory; do not promise stable deployment access.
5. **Academic application:** seek written scope for Alpha Vantage or an institution-backed Twelve Data grant. SiftingIO's student program is available to investigate, but its price methodology prevents treating it as an equivalent exchange quote source.

## Acceptance before integration

- Discover the actual MCP tool schemas, then call allowed read-only tools for NVDA, AMD, INTC, and QCOM. Verify that every response identifies the requested company; reject sample-symbol substitution.
- Establish price currency, timestamp, timezone, session, feed/venue, and any delay. An IEX snapshot, an EOD close, a delayed quote, and a synthetic reference value are different observation types.
- Verify company shares, split adjustments, current market capitalization, cash/debt dates, and estimate accounting basis/fiscal horizon. Use compatible inputs in Quant; retain actual formulas and source metadata.
- Refresh or acquire the periods needed for a trailing-twelve-month denominator. Current price divided by an old FY2025 amount is a fiscal-year multiple, not automatically current trailing P/E.
- Check four-company peer comparisons, unavailable estimates, zero/loss earnings, stale data, market closure, quota exhaustion, upstream errors, and cache freshness in direct tools and the actual application.
- Confirm permission for the intended public coursework browser deployment. Personal/internal free access and public display/redistribution are separate plan questions; MCP transport does not change those entitlements.
- Start with on-demand snapshots and caching. A chat brief can use dated request/response observations; continuous streaming can remain a separate requirement.
